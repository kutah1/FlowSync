# Types

Contains TypeScript type definitions and interfaces for the entire application.

## What goes here:
- TypeScript interfaces
- TypeScript types
- API response types
- Component prop types
- Entity/model types
- Global type declarations

## Examples:
- `User.ts` - User interface
- `Task.ts` - Task/Project interface
- `ApiResponse.ts` - Generic API response type
- `index.ts` - Export all types

## Note:
Keep related types organized in separate files. Use descriptive names matching the entity they represent.
