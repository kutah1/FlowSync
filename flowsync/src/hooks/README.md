# Hooks

Contains custom React hooks that encapsulate component logic and can be reused across components.

## What goes here:
- Custom React hooks (useState, useEffect logic wrapped)
- Hooks for data fetching
- Hooks for form handling
- Hooks for authentication
- Hooks for common operations

## Examples:
- `useFetch.ts`
- `useForm.ts`
- `useAuth.ts`
- `useLocalStorage.ts`
- `useDebounce.ts`

## Naming convention:
All hooks must start with `use` (e.g., `useMyHook.ts`)
