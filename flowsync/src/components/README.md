# Components

Contains reusable UI components that are independent and can be used across multiple pages.

## What goes here:
- Small, focused UI components (buttons, modals, cards, etc.)
- Presentational components without business logic
- Components that are used in multiple places across the app
- Component prop interfaces/types

## Examples:
- `Header.tsx`
- `Button.tsx`
- `Modal.tsx`
- `Card.tsx`
- `Navbar.tsx`

## Structure:
Each component should ideally have its own folder if it has multiple related files (styles, tests, etc.)
