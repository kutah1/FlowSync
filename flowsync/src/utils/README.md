# Utils

Contains utility/helper functions for common operations and transformations.

## What goes here:
- String manipulation functions
- Date/time utilities
- Number formatting functions
- Array manipulation helpers
- Validation functions
- General-purpose helper functions

## Examples:
- `formatDate.ts`
- `formatCurrency.ts`
- `stringUtils.ts`
- `arrayHelpers.ts`
- `validators.ts`
- `logger.ts`

## Note:
Utility functions should be stateless, pure functions with no side effects.
