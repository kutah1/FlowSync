# Assets

Contains static files and media used throughout the application.

## What goes here:
- Images (PNG, JPG, SVG, etc.)
- Icons
- Fonts
- Videos
- Other static media files

## Organization:
Consider organizing by type if you have many assets:
- `images/`
- `icons/`
- `fonts/`
- `videos/`

## Note:
Keep file names lowercase with hyphens (e.g., `hero-image.png`, `logo-icon.svg`)
