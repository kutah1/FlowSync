# Constants

Contains application-wide constants and configuration values.

## What goes here:
- API endpoints
- Application settings
- Magic strings/numbers
- Enum-like values
- Configuration constants
- Default values

## Examples:
- `apiEndpoints.ts` - API base URL and endpoints
- `appConfig.ts` - App-wide configuration
- `errorMessages.ts` - Error and warning messages
- `enums.ts` - Status enums, role enums, etc.
- `defaults.ts` - Default values for settings

## Note:
Use UPPER_SNAKE_CASE for constant names. This makes constants easy to identify.
