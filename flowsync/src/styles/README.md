# Styles

Contains global styles, theme configuration, and shared styling utilities.

## What goes here:
- Global CSS/SCSS files
- Theme configuration
- Tailwind config or CSS-in-JS theme
- CSS variables
- Reset/normalize styles
- Shared styling utilities

## Examples:
- `globals.css` - Global styles
- `theme.ts` - Theme configuration
- `variables.css` - CSS custom properties
- `mixins.scss` - SCSS mixins

## Note:
Component-specific styles should stay with their components. This folder is for truly global styles.
