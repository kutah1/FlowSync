# Pages

Contains page-level components that represent different routes/views in your application.

## What goes here:
- Full page components (landing, dashboard, settings, etc.)
- Components that correspond to specific routes
- Page-specific logic and state management
- Components that compose smaller components

## Examples:
- `HomePage.tsx`
- `DashboardPage.tsx`
- `SettingsPage.tsx`
- `NotFoundPage.tsx`

## Note:
Pages should be containers that use components from the `components` folder.
